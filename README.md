# Ejercicios y prácticas DAM

Colección de **ejercicios y prácticas desarrolladas durante el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM)**.

Este repositorio reúne trabajos de distinto tamaño realizados durante la formación y sirve como histórico de aprendizaje y evolución técnica.

## Algunos contenidos

Entre las prácticas y proyectos incluidos se encuentran:

- **Agenda**
- **Concesionario**
- **GestiónHotel**
- **hotelapi**
- **Ficheros**
- **Flujos de objetos**
- **Usuarios**
- **Ejercicios de recursividad**
- **Primeros ejercicios con Flutter**

## Tecnologías y conceptos trabajados

A lo largo de estos ejercicios se practican, entre otros:

- Java
- Programación orientada a objetos
- Acceso y persistencia de datos
- APIs
- Gestión de ficheros
- Recursividad
- Desarrollo de aplicaciones de gestión
- Flutter / Dart

## Objetivo del repositorio

El objetivo es conservar una muestra del trabajo práctico realizado durante DAM. Para proyectos de mayor alcance y más representativos de mi perfil actual, consulta los repositorios destacados de mi perfil, especialmente **Plataforma-Pago-Cashless**.
